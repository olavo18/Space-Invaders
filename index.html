SOBRE O PROJETO

Este jogo é uma releitura do clássico Space Invaders de 1978, desenvolvido por Olavo como um projeto de programação moderno.

Diferente do original, esta versão conta com mecânicas de aceleração progressiva, visuais em neon e uma narrativa própria que você conhecerá ao iniciar a partida.

Inspirado no real, modificado para o futuro.
